# Local development

This checkout also contains the [Linux setup](linux/README.md),
[drum lane development notes](docs/drum-lanes.md), and pinned engine and asset
libraries in `third_party/`. Start with `python3 tools/bootstrap.py` to prepare
development tools. Use `--install-dotnet` to install the required SDK locally.
See [building.md](building.md) for the Deluxe build pipeline.
